DOM manipulation

Overview and quick reference

I recommend learning what the DOM is if you have time. There is an MDN article at the bottom to help

Find elements with querySelector and querySelectorAll

querySelector gives you the first match (or null). querySelectorAll gives you a list of all the current matches. 


// find the first button on the screen
const button = document.querySelector("button");

// find the element with id="snacks".
const snackList = document.querySelector("#snacks");

// find the first element with class="highlight".
const highlight = document.querySelector(".highlight");

// find the first button with type="button".
const plainButton = document.querySelector('button[type="button"]');

// find every list item inside #snacks.
const snacks = document.querySelectorAll("#snacks li");

React to events with addEventListener

Each dom element can listen for events that happen on it.


// Run when the button is activated by a click, tap, or keyboard.
button.addEventListener("click", () => {
console.log("The button was activated");
});

// Run when a key is pressed on the page. event.key tells you which key.
document.addEventListener("keydown", (event) => {
console.log(event.key);
});

// Run when the browser window changes size. If you want to know what the window vs. document objects
//are, mdn has good docs on that. Basically window is everything about the current window, document is
all
// the stuff you see, and navigation is stuff like history
window.addEventListener("resize", () => {
console.log(window.innerWidth);
});

More events on MDN: event reference, typing in a field, submitting a form.

Change text and classes with innerText and classList


button.innerText = "Add a snack";
button.classList.add("highlight");
button.classList.remove("highlight");
button.classList.toggle("highlight"); // Add it if missing, remove it if present.

Put an element on the page with appendChild

createElement makes an element in JavaScript. Call appendChild on the parent to put it after the parent's existing children.


const message = document.createElement("p");
message.innerText = "Snack time!";
document.querySelector("main").appendChild(message);
