Objecs

Overview

Objects are probably the most important data type we'll be working with. If you've ever heard of JSON, it stands for Javascript Object Notation. You can think of objects as just key-value pairs, almost like a dictionary in Python. Theyir use cases are a little different from maps or dictionaries, rather I'd think of them almost as a class with no methods.
